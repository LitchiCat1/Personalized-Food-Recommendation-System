# 直接 100 人壓力測試結果

100 人同時嘗試連線與操作，39 人完成整輪、61 人未完成，實測 19.989 秒。本輪未通過 100 人同時操作的品質條件。

使用原有 100 個專用帳號，依網站限流事先登入。登入完成後關閉準備連線，以同步起跑點讓 100 個獨立 HTTP 工作階段同時嘗試。每人先驗證登入，再查食物、查紀錄與歷史，接著新增、修改、核對、刪除一筆臨時飲食紀錄，共 8 次依序請求。首次連線失敗者結束該人的流程，沒有反覆重試。

這是 100 人同時湧入的一輪突發測試，不是 100 人維持數分鐘的測試。完成整輪的人數不能當作穩定同時容量。單一負載產生器經公開 Funnel，另有獨立健康檢查連線；未取得伺服器 CPU、記憶體、TCP 或後端紀錄，無法把瓶頸歸因於 Tailscale 或後端。未測整頁載入、照片、AI 或 Places。

前一輪已驗證 20 人持續 60.485 秒、1,421 次請求全部成功。它的工作負載與本次突發不同，應分開解讀。

測後 100/100 帳號驗證通過，300 筆原紀錄保留，臨時紀錄與本輪待登出憑證 0。
