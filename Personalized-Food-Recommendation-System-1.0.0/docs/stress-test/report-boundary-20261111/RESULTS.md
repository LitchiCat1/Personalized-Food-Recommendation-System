# 每 10 人一級壓力測試結果

本輪已驗證最高 20 人保持連線操作約 60 秒，1,421 次請求全部成功，約 95% 在 0.23 秒內回應。這是本次路徑與操作頻率的通過證據，真正的系統最大容量仍未確定。

沿用既有 100 個專用帳號與 300 筆保留紀錄，沒有再創帳號。先補測 18、19、20 人，再依使用者要求以 20、30、40、50、60、70、80、90、100 人逐級檢查。每個帳號各自保持 HTTP 連線，查食物、查紀錄與歷史、新增、修改、驗證、刪除臨時紀錄，每輪後休息 4–6 秒。每級先測 20 秒，最高通過級別再測 60 秒；若無法完整準備連線，該級不開始業務操作。

20 人在第一回三次準備連線失敗，第二回曾成功開始操作。這表示準備連線的結果會隨當時狀態變動，不能宣稱有固定的 19 人上限，也無法只由客戶端數據判斷瓶頸來自 Tailscale 或後端。
