## Subject

Clarification of AFCD F001301 reuse in a free university project

## Message

Dear FSANZ team,

I am a university student in Taiwan working on a non-commercial graduation project. The project is a free food nutrition application. We are reviewing the Australian Food Composition Database entry F001301, “Bok choy, raw,” and the FSANZ Data User Licence Agreement based on CC BY-SA 3.0 Australia.

Before using or downloading any AFCD data, we would appreciate general guidance on whether the licence permits the following proposed use, and what conditions would apply:

1. Retaining selected nutrient values and source provenance from this single food entry in a private SQLite database on our application server, including user-specific nutrition profile or meal snapshots and routine backups.
2. Returning those selected values to authenticated users through the application API and displaying them in a read-only nutrition preview. The application is publicly accessible but free and non-commercial.
3. Converting the selected source cells into a fixed JSON schema used by the application. An external search/extraction service and an AI model may assist with locating the public record and selecting the corresponding source cells; the application server would validate the selections and calculations. We would not ask the model to invent values or infer missing values.
4. Providing attribution, the licence link, the data limitation statement, the Australian-data suitability notice, copyright notices and disclaimers. Please advise where these notices should appear for API responses, user screens, exports, saved snapshots and backups, and whether any format-specific requirements apply.
5. Determining whether this selected single-entry JSON profile is a Derivative Work or contains a substantial part of the AFCD Work, and whether ShareAlike would apply to the data profile only or affect any other part of the application. We understand the agreement distinguishes a Collection from a Derivative Work and does not automatically license independent material in a Collection; we are seeking guidance on how that distinction applies to this proposed profile.
6. Understanding whether the relevant F001301 data has third-party source material or restrictions that must be cleared separately before this use.

Could you also confirm whether the answer differs between using the public food-detail webpage and downloading the AFCD data files? We have not accepted the licence, downloaded AFCD files, or copied nutrient values into our project. We will keep this source out of the application until the reuse conditions are clear and the project owner has reviewed the applicable terms.

We are seeking information about the FSANZ licence and its conditions, not legal advice or an endorsement of our application. If this enquiry should be directed to a different team or rights holder, would you please provide the appropriate contact or forward it where possible?

Thank you,
