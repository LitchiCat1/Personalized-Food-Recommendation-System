測試方法

先讓 30 人直接同時開始，每人使用獨立 HTTP 工作階段。通過便往 45、70、100 人增加；失敗則確認較低人數，再以二分法縮小到相鄰人數。每級約 20 秒，最高短測通過者確認 120 秒，之後重測上方相鄰級別。每人首輪 8 次 API，之後每輪 7 次，輪間休息 4–6 秒；登入事先限流準備。

整級完整測完、請求失敗率低於 1%、含首次連線的整體 P95 低於 2 秒、每人至少完成一輪，且有失敗流程的人數比例低於 1%。本輪級別均低於或等於 100 人，因此任何一人流程失敗即不通過；此時停止該級後續循環，已開始的請求仍完成或逾時。
