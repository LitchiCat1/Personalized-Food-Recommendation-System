# 併發容量搜尋結果

本輪已驗證約 19 人同時進行基本資料操作，持續 120.610 秒，2,602 次請求、0 次失敗，整體 P95 0.19 秒。相鄰 20 人補測未通過，1 人首次連線失敗。這是本次單一來源、公開連線路徑與操作頻率下的結果，並非後端或 Tailscale 的固定最大值。

先讓 30 人直接同時開始，每人使用獨立 HTTP 工作階段。通過便往 45、70、100 人增加；失敗則確認較低人數，再以二分法縮小到相鄰人數。每級約 20 秒，最高短測通過者確認 120 秒，之後重測上方相鄰級別。每人首輪 8 次 API，之後每輪 7 次，輪間休息 4–6 秒；登入事先限流準備。

整級完整測完、請求失敗率低於 1%、含首次連線的整體 P95 低於 2 秒、每人至少完成一輪，且有失敗流程的人數比例低於 1%。本輪級別均低於或等於 100 人，因此任何一人流程失敗即不通過；此時停止該級後續循環，已開始的請求仍完成或逾時。

只用一台電腦經公開 Funnel，另有健康檢查連線，沒有伺服器 CPU、記憶體、即時 TCP 或後端 access log。前輪 20 人曾通過約 60 秒，也曾準備失敗，顯示連線結果會變動。不能宣稱固定 18、19 或 20 人上限，也沒有證實由 Tailscale 限制人數。未測整頁載入、照片、外部 AI／Places 或數小時運作。
